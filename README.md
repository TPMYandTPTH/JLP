## 1. 会社紹介

TPは**1978年にフランス・パリで設立**されたグローバルBPO（ビジネスプロセスアウトソーシング）企業です。世界100カ国以上、50万人以上の従業員を擁し、カスタマーエクスペリエンスの分野で世界をリードしています。

最先端のテクノロジーと優れた人材を融合させ、世界中の有名ブランドに最高のカスタマーエクスペリエンスを提供。現在、**日本語スピーカーを対象に、マレーシアおよびタイにて積極的な採用活動**を行っています。新卒の方から経験豊富なプロフェッショナルまで、皆さまの語学力と個性が活かせる、多文化で働きやすい職場環境が用意されています。マレーシアとタイを合わせて**500名以上の日本語話者スタッフ**が在籍し、現在も増加中です。

### 私たちのミッション

> 「**Each interaction matters**」— 一つひとつの顧客対応に真摯に向き合い、クライアント企業の成功を支援することが私たちの使命です。

多様性を尊重し、従業員一人ひとりの成長を支援する環境づくりに注力。グローバルな視野と、ローカルな細やかさを併せ持つサービスを提供しています。

### 認定・受賞歴

| 認定 | 内容 |
|---|---|
| 🏆 Great Place to Work® | マレーシア拠点 **6年連続受賞** |
| 🌍 World's Best Workplaces™ | グローバルで **5年連続認定** |
| 📈 成長企業 | 日本語スピーカー採用を継続的に拡大中 |

> 公式発表：TPはGreat Place to Work®により「World's Best Workplaces™」として5年連続で認定されました。「この認定は、私たちの従業員からのフィードバックと信頼に基づいており、私たちの企業文化の強さを示しています。」

### TPを選ぶ7つの理由（サイト記載）

1. **グローバルな環境で、自分をレベルアップ！** — 世界中から集まったスタッフが活躍する国際的な環境で、自然と英語力や異文化理解力がアップ。
2. **日本語スピーカー向けのポジションが豊富！** — 日本語中心の業務から安心してスタートでき、段階的に英語に触れながらスキルを伸ばせる。英語バイリンガルポジションも豊富。
3. **日本人サポートも充実！** — 多数の日本人スタッフが在籍し、生活・仕事の両面で相談できる環境。
4. **実力次第でキャリアアップのチャンス！** — 年齢や経歴に関係なく「頑張り」を評価する社風。トレーナー、QA、チームリーダー、マネージャーへの昇進や、別プロジェクトへの異動などのキャリアパス。
5. **就労ビザ＆一時滞在先サポートあり！** — 就労ビザ申請サポート、空港送迎（マレーシアのみ）、一時滞在先の手配まで、入社前後の手続きをフルサポート。
6. **多様性あふれる、自由でフラットな社風** — 国籍・年齢・性別を問わず、お互いを尊重し合える文化。
7. **仕事だけじゃない！イベント＆福利厚生も充実** — 社内イベント、表彰制度、チームビルディング、医療保険、有給休暇、各種手当なども完備。

## 5. 移住・ビザサポート

初めての海外移住も安心してスタートできるよう、以下のサポートが用意されています。

### 入社までの流れ（概要）

1. 内定条件・入社時期の調整
2. 必要書類のご提出（書類案内）
3. 就労ビザ申請（専門チームが実施、会社負担）
4. 航空券手配（片道航空券・到着日の確定）
5. 到着サポート（空港送迎・ホテル）
6. 研修開始（入社手続き・トレーニング）

### 就労ビザ（Employment Pass, EP）

- 申請費用：会社負担
- 発行目安：内定から約2ヶ月
- 日本語サポート：必要書類のご案内・申請進捗の共有

### 家族帯同（Dependent Pass）

就労ビザ（EP）取得後、配偶者・お子さま向けのDependent Pass申請が可能です。日本語医療機関や日本人学校／コミュニティもあり、帯同での移住例も多くあります。

### 国・都市別の特徴

- **マレーシア（KL／ペナン）**：多文化で英語が広く通じ、日本語施設も充実。KLは都市型、ペナンは海や自然も身近。到着後のホテルを手配。
- **タイ（バンコク）**：日本語施設・病院が非常に充実。BTS/MRTで移動しやすく、家具付きコンドで快適に生活。到着後のホテルを手配。

## 6. 選考プロセス

日本人担当者が応募から入社まで伴走します。すべてオンラインで完結し、各ステップで日本語サポートがあります。

### 選考フロー（標準）

| ステップ | 内容 |
|---|---|
| 1. 応募書類提出 | 履歴書／職務経歴書 |
| 2. 書類選考 | 目安：3営業日 |
| 3. 面接①（採用担当） | 日本語中心／30〜45分 |
| 4. 面接②（現場マネージャー） | 30〜45分 |
| 5. 適性検査 | 日本語・英語アセスメント、ロールプレイなど |
| 6. 結果連絡 | 目安：1週間 |

※プロジェクトにより順序・内容が前後・省略される場合があります。選考回数は合計2〜3回、全体の選考期間目安は2〜3週間です。使用ツールはMicrosoft Teams。

### オンライン面接のポイント

- **入室**：招待リンクをクリックしてブラウザまたはアプリで参加。表示名は「フルネーム（ローマ字）」推奨。

- **服装**：清潔感のあるオフィスカジュアル。

## 15. よくある質問（FAQ）

**Q. 英語に自信がなくても応募できますか？**
はい、日本語中心のポジションが多数あります。入社後にGoFluentなどの英語学習支援プログラムもあるので、段階的にスキルを伸ばすことができます。

**Q. 就労ビザの手続きは難しいですか？**
会社が申請を代行します。必要書類の準備も日本語でご案内し、申請から承認まで全てサポートします。

**Q. 住居はどうやって探せば良いですか？**
現地エージェントの紹介やオリエンテーションでのアドバイスを提供します。マレーシアでは一時滞在先の手配もあり、落ち着いて物件を探せます。

**Q. シフト勤務はありますか？**
プロジェクトにより異なります。日勤のみのプロジェクトもあれば、シフト勤務のプロジェクトもあります。

**Q. 日本語だけで仕事はできますか？**
多くのポジションで日本語がメインです。社内コミュニケーションでは基本的な英語が必要な場合もありますが、語学サポートがあります。

**Q. 福利厚生にはどんなものがありますか？**
医療保険、有給休暇、各種手当（夜勤・住宅等）、語学研修（GoFluent）、社内イベント、キャリア開発プログラムなどがあります。

**Q. 応募から入社までの期間はどのくらいですか？**
通常、応募から内定まで2〜3週間、ビザ申請から承認まで4〜6週間程度です。個人差がありますので、詳細はお問い合わせください。

**Q. カジュアル面談とは何ですか？**
面接ではなく、TPでの仕事や生活について気軽に相談できる30分程度のオンライン面談です。転職を迷っている方もお気軽にどうぞ。

**Q. 家族帯同はできますか？**
就労ビザ取得後、配偶者・お子さまのDependent Pass申請が可能です（国・雇用条件により異なるため個別にご案内）。
